# Retained A to fresh B evidence boundary

The original retained-A/fresh-B design required five host-owned, quiescent intermediate snapshots during one B session. That stronger guarantee remains historical evidence; it is not implemented or silently represented by this case. The approved native-boundary amendment replaces those intermediate snapshots with cooperative task-record observations and native call/output/child-read evidence, plus a mandatory independent raw semantic audit. It does not weaken the requirement that check starts and packets actually precede checks or dispatches.

Host-owned source, restored-pre, post-injection and final captures remain at supported quiescent native boundaries. The source packet, source online reward 0 and source versus target job/receipt identities stay distinct. The exact fixed STATE injection remains host-attributed. Target agent context receives durable files only, never source native logs, transcript or cache.

The final task record must contain unique linked check-start observations before the corresponding completed-check rows. Their timestamps and prior existence are agent-authored claims. Native target calls must independently show both TEST-C1 commands, working directory, results and ordering, and correlated children must themselves read the full appropriate packets before any unrecognized tool work. Full task/spec/check/diff/review/configuration/ownership packet content and fresh reviewer/repair lineage remain required. Unsupported or opaque forms are incomplete.

An independent reviewer must bind its raw audit to exact source and target execution, case/code/configuration/candidate/gate and retained raw evidence identities. That reviewer must inspect actual parent calls and outputs to establish check-start observations and complete packet writes before the relevant checks or dispatches. A final file, agent timestamp, parent claim or child read after dispatch does not establish an earlier write. Missing, ambiguous or contradictory raw evidence is incomplete. A claimed audit boolean is insufficient.

The automatic verifier reports structural evidence only, `semantic_audit: required`, and **incomplete**, even when every implemented structural predicate holds. It must not return a passing binary reward or cause reporting to count a behavioral pass before the independently bound raw audit. Shared host provenance, one-use admission before authentication, resource bounds, and no-auth native proof still require separate integration and review. No model call is authorized by this file.
