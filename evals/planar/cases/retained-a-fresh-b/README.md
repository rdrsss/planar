# Retained A to fresh B

`retained-a-fresh-b` is registered with the case-selected evaluation launcher. Planning requires paired frozen case and candidate snapshots, the closed source packet, a reserved execution ID, a timezone-aware expiry, medium effort and the 1050-second job budget. Execution additionally requires an independently reviewed, matching one-use gate; the launcher consumes it before authentication and uses the shared account admission lock. See [evaluation guidance](../../../README.md) for the launcher arguments and account resolution procedure.

The source policy fixes the reviewed a8f4 retained source, including its original online failure and reward 0. The case-local validator checks the closed source packet and reruns the corrected A verifier in its pinned, network-disabled image. That cached assessment does not change the original online outcome. The restoration helper rebuilds Git from the approved base bundle and restores only selected durable files and owned product outputs; the host captures the supported quiescent boundaries and injects the fixed state defect.

A source packet contains private native logs and must remain outside the target workspace and model context. The target receives only its ordinary durable files. The packet policy uses a fixed case inventory; its digest binds the artifact hashes and source identity. Source and target capture times and provenance remain separate.

The separate verifier checks restoration, injection, final state, packet and revision structure, target lineage, actual checks and correlated child packet reads. Per [CONTRACT.md](CONTRACT.md), intermediate start observations and packet-write timing remain cooperative evidence subject to an independent raw trace audit. Even when structural checks pass, the result remains **incomplete with reward 0**; a bound independent raw audit and reviewed host provenance are required before acceptance. Unsupported native forms remain incomplete.

A no-auth Harbor/Docker control exercised restoration, injection, separate network-disabled verifier handoff and cleanup with synthetic target logs. It does not establish a genuine B review, repair or pass. This directory does not itself approve a gate or authorize a live run.
