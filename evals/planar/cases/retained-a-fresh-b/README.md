# Retained A to fresh B: offline components

This directory is **not registered or executable as a Harbor case**. Its source policy fixes the reviewed a8f4 retained source and includes the original online failure. The case-local source validator checks the closed source packet and reruns the corrected A verifier in its pinned, network-disabled image. The restoration helper installs the approved clean base bundle, verifies Git stage/status and restores only captured durable home files and owned product outputs. The separate restoration verifier checks fresh target receipts and the sole host-attributed state injection; it deliberately does not grade B.

A source packet contains private native logs and must remain outside the target workspace and model context. The target receives only its ordinary durable files. The packet policy is a case-selected fixed inventory, not a generic importer. Packet SHA is over canonical policy including every artifact hash and source binding. Source and target capture times are separate.

The following are not yet implemented here: registered launcher/admission and source/gate/reserved-ID binding, fixed host injection and target capture integration, reviewed target host provenance binding and reward admission, finite budget enforcement, and actual no-auth Harbor Nop/Docker restore/handoff/cleanup proof. Until those are independently implemented and reviewed, no gate, auth access, model call or target reward is authorized by this directory. The isolated A regrade does not change the source online reward 0.

The candidate separate verifier composes source, supported quiescent restoration/injection/final boundaries, bounded TS-8.4 packet/revision structure, target native lineage, actual check calls and correlated child packet reads. Per [CONTRACT.md](CONTRACT.md), intermediate start observations and packet-write timing remain cooperative evidence subject to an independent raw trace audit, not host attestations. The verifier deliberately returns incomplete and reward 0 even when structural checks pass; a bound independent raw audit and reviewed host provenance are required before any acceptance. Unsupported native forms remain incomplete.
